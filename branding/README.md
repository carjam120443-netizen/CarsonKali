# CarsonKali Branding

This directory contains the official CarsonKali project branding assets.

## Assets

- `carsonkali-logo.svg` — primary vector logo for the distro and project documentation.
- `README.md` — branding notes and usage guidance.

The SVG is intentionally vector-based so it can be reused for the README, ISO artwork, desktop branding, wallpapers, icons, and future installer assets without losing quality.

## Identity

CarsonKali uses a dark terminal-inspired base with a stylized blue **C** and command-prompt symbol. The design is custom CarsonKali branding and is not intended to replace or imitate the Kali Linux trademarks.
