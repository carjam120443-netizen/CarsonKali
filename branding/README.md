# CarsonKali visual identity

CarsonKali uses an independent visual identity and must not reuse Kali Linux's dragon logo, wallpapers, boot artwork, or official branding.

## Initial direction

- Primary palette: deep charcoal, electric violet, and cool cyan
- Style: clean, modern, technical, and readable
- Logo concept: an original geometric "CK" mark
- Wordmark: CarsonKali
- Desktop: KDE Plasma with a restrained, usable default layout

## Asset locations

- `wallpapers/` — desktop backgrounds
- `plymouth/` — boot splash assets
- `grub/` — boot menu theme
- `icons/` — project-specific icons

All assets added here should be original or appropriately licensed. Do not imply official affiliation with Kali Linux or Offensive Security.
